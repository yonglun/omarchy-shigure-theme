# Shigure II · 月下

**月・雨・雪・潮。月明かりの下に、静かな藍色のデスクトップを。**

[English](README.md) · 日本語 · [简体中文](README.zh-CN.md)

![Shigure II — 遠景の湾と月](preview.png)

**Omarchy 4.0** 向けのダークテーマ。墨を思わせる藍色の背景に、生成りの文字、
古金色の操作アクセント、月白のカーソル、古金色から青灰色へ移るフォーカス枠を組み合わせました。
**月・雨・雪・潮**の異なる四つの構図が、落ち着いた作業空間をつくります。標準の壁紙は月です。

## 風景の中で、仕事をする

Shigure II の着想源は、**歌川広重の浮世絵**です。繊細な墨の輪郭線、平面的な色面、
ぼかし摺り、墨と紙の余白の関係を大切にしています。非対称の横長の構図と広い余白によって、
その表現を現代のデスクトップに取り入れました。

広重の [Eight Views of Kanazawa at Night](https://www.clevelandart.org/art/1924.967)
を、月光、低い岸辺、水平に重なる景色の参考にしています。遠景の月と湾、雨の中の二本の傘、
人のいない雪道、真上から見た潮という四つの構図に展開しました。古金色が操作を示し、藍色が画面を支えます。

## インストール

現在は **Shigure II のローカル候補版**です。ダウンロードまたは展開したテーマのフォルダー内で、
以下を実行し、**Omarchy 4.0.x** の新しい `shigure-ii` ディレクトリにインストールします。
初版の `shigure` と共存できます。既存の `shigure-ii` がある場合は先にバックアップしてください。
同名ファイルは上書きされます。

```bash
mkdir -p ~/.config/omarchy/themes/shigure-ii/backgrounds
cp colors.toml icons.theme preview.png ~/.config/omarchy/themes/shigure-ii/
cp backgrounds/*.png ~/.config/omarchy/themes/shigure-ii/backgrounds/
omarchy theme set shigure-ii
```

必要に応じて次の壁紙へ切り替えられます（月 → 雨 → 雪 → 潮の順に循環）：

```bash
omarchy theme bg next
```

初回適用時は、ファイル名順で **Moon（月）** が最初に選ばれます。以降の壁紙選択は
Omarchy のバージョンに従います。冒頭の画像は **1600 × 900 の壁紙表示用コピー**で、
実際のデスクトップのスクリーンショットではありません。

**この候補版をリポジトリに公開した後**は、URL からインストールできます。

```bash
omarchy theme install https://github.com/yonglun/omarchy-shigure-theme
```

URL インストーラーは `shigure` という名前を設定し、テーマを適用します。初版と同じディレクトリ名を
使うため、既存の `shigure` があれば先にバックアップしてください。今回の候補版はまだ公開しておらず、
実際の Omarchy セッションへのインストールも行っていません。

|:---:|:---:|

画像をクリックすると元の壁紙が開きます。四枚とも文字なしの **1672 × 941 PNG / RGB** で、
**ICC プロファイルは埋め込まれていません**。実際の生成寸法を保ち、縦横比はほぼ 16:9。
拡大や追加の色調整は行っておらず、ネイティブ 4K 画像ではありません。
ギャラリーは **1024 × 576 JPEG** の表示用コピーです。四枚とも同じテーマパレットを使います。

## 配色

![Shigure II のパレット](docs/images/palette.svg)

| 役割 | 色 | 用途 |
|---|---|---|
| 墨藍 | `#101F2B` | メイン背景 |
| 浅い藍 | `#1B3040` | 補助サーフェス |
| 生成り | `#E3DDCF` | 本文 |
| 月白 | `#F0E7D5` | カーソル、明るい文字 |
| 古金 | `#CBB98B` | 選択中の項目、操作アクセント、枠グラデーションの始点 |
| 青灰 | `#84A7BD` | 青系の構文色、枠グラデーションの終点 |
| 水緑 | `#8FB8B5` | シアン系の構文色 |
| 松葉 | `#9CAC89` | 緑系の構文色 |
| 朱 | `#CE887D` | 赤の意味色 |
| 黄土 | `#D3B57D` | 黄色系の構文色 |

フォーカス枠は `rgba(CBB98Bee) rgba(84A7BDee) 45deg` です。初版から変更したのは
`accent`、`bright_foreground`、`hyprland_active_border` の三項目のみで、その他の意味色は維持しています。
独自の色であり、歴史的な顔料の標準色を示すものではありません。

本文とメイン背景のコントラスト比は **12.38:1**、選択中の文字は **7.24:1** です。
古金色はメイン背景に対して **8.66:1**、補助サーフェスに対して **7.03:1**。
不透明な指定色どうしの測定値であり、全アプリの最終表示を保証する値ではありません。

## Omarchy との互換性

[`colors.toml`](colors.toml) にセマンティックパレット、明示的な `mode = "dark"`、明るい色群、
対応するフォーカス枠グラデーションを定義しています。端末、エディター、Hyprland、シェルの設定は
Omarchy 自身のテンプレートから生成されます。[`icons.theme`](icons.theme) は `Yaru-prussiangreen` を
指定しています。実行可能なテーマフックやアプリごとの設定上書きは含みません。

検証は公式 **v4.0.0** を対象としています。[検証範囲と制限](docs/COMPATIBILITY.md)および
[検証記録](docs/VALIDATION.json)を参照してください。この macOS 作業環境では、実際の Omarchy
デスクトップへのインストール確認は行っていません。

## 作品と利用

本コレクションは歌川広重の浮世絵に着想を得た、新たに生成した現代的な解釈です。
歴史的な版画やスキャン画像ではありません。技術面では 2026-10-01 に OpenAI 内蔵 ImageGen を
使用しました。[制作記録](docs/ARTWORK.md)から、完全なプロンプト、修正前後の比較、元画像の実測情報を参照できます。

Shigure II はコミュニティによるテーマで、Omarchy の公式プロジェクトとは独立しています。
初版は Git コミット `ceb04250c1e9816c83f909e599e924f12b57467c` に保存されています。
設定、ドキュメント、収録画像は [MIT ライセンス](LICENSE) で配布します。
派生版を公開する際は、Shigure へのリンクを添えていただけると幸いです。
